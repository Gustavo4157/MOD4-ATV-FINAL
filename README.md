# GameStore API

Serviço RESTful construído com **FastAPI** e **SQLAlchemy** para o controle de estoque de uma loja de games, abrangendo o cadastro de plataformas (PC, PlayStation, Xbox, etc.), o catálogo de títulos e o sistema de avaliações de usuários.
